Detailed Description

Composite multi-level solve of an MLNodeLaplacian with hypre.

The composite operator of MLMG + MLNodeLaplacian is (up to a lumped-mass row scaling and extra fine-equation terms in the coarse/fine rows) the bilinear/trilinear finite-element operator with hanging-node constraints. This class assembles the symmetric form S = Q^T K Q, where K sums the Q1 element matrices of all cells not covered by a finer level and Q maps coarse/fine fine-level nodes to the coarse unknowns by multilinear interpolation. The right-hand side is transformed so that the solution equals MLMG's composite solution (up to a constant for singular problems, which are made consistent with nodal-volume weights; with an inconsistent composite right-hand side this differs slightly from MLMG's correction).

Supports the Sigma coarsening strategy with scalar, constant or mapped (per-direction) sigma, Cartesian coordinates, and refinement ratios 2 and 4; and, in EB builds, the RAP strategy with embedded boundaries, where the element matrices of cut cells are integrated over their fluid part (MLNodeLaplacian's EB integrals), covered cells are skipped, and nodes without fluid are not unknowns. At coarse/fine nodes next to cut cells this composite operator is the consistent finite-element one, whereas MLMG's reflux treats the cells there as regular.

The solver is configured with the HypreIJIface keys under the given ParmParse prefix (default "hypre_mlnodelap"). Further keys:

  • <prefix>.backend = hypre | algmg (default hypre): solve the assembled system with hypre or with AMReX's AlgMG, configured by <prefix>.algmg.* (see composite::algmg_parse_options).
  • <prefix>.dump_matrix = N (default 0): write the systems of the first N solves with this dump prefix (counted over all objects of the run) in Matrix Market format for external analysis: for solve k, <dump_prefix>_<k>_A.mtx, _b.mtx, _x.mtx (matrix, right-hand side, solution) and _rows.txt (per row: level, node index, scaling). The dumped system is the one solved, S' x' = b' with S' = s S s, b' = s b, x = s x'. <prefix>.dump_prefix defaults to the ParmParse prefix. Files with more than <prefix>.dump_gather_max values (matrix entries, or vector and row-map values; default 5e7) are written one per rank, as <file>.<rank>.
  • <prefix>.eb_scaling (default 1): in EB builds, scale the unknowns by 1/sqrt(nodal fluid fraction) so that rows next to small cut cells count in the residual norm.
