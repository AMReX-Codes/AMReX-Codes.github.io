Detailed Description

template<typename T>
class amrex::JacobiSmoother< T >

Jacobi smoother for AlgVector/SpMatrix linear systems.

Performs x += w * (b - A x) / d sweeps, where d is the diagonal of A (weighted Jacobi, weight 2/3 by default) or, with setL1(true), the l1 row norm sign(a_ii) * sum_j |a_ij| (l1-Jacobi, weight 1 by default), which converges for any symmetric positive definite matrix [Baker, Falgout, Kolev, Yang, SIAM J. Sci. Comput. 33 (2011), 2864-2887].
