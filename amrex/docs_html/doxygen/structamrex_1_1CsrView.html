Detailed Description

template<typename T, typename Index = Long>
struct amrex::CsrView< T, Index >

Lightweight non-owning CSR view that can point to host or device buffers.

The template parameter T controls constness of the value array; the column/row arrays follow suit. Index is the type of both the column indices and the row offsets.
