Detailed Description

template<typename T, typename I = Long>
struct amrex::CsrView< T, I >

Lightweight non-owning CSR view that can point to host or device buffers.

The template parameter T controls constness of the value array; the column/row arrays follow suit. I is the type of both the column indices and the row offsets.
