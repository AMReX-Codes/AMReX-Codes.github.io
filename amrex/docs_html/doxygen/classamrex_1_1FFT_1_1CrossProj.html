Detailed Description

template<typename MF = MultiFab>
class amrex::FFT::CrossProj< MF >

FFT-based projection of a cell-centered velocity field onto the space of fields that are divergence free with respect to the node-centered cross-stencil divergence.

The divergence at each node is computed from the 4 (2D) or 8 (3D) cells surrounding it. Currently only all-periodic boundaries are supported, in 2D and 3D, with at least 2 cells in each direction. The first AMREX_SPACEDIM components of the MFs are the velocity.
