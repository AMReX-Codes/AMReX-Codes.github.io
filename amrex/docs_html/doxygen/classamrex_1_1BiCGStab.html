Detailed Description

template<typename V, typename M>
class amrex::BiCGStab< V, M >

BiCGStab solver with right preconditioning.

The operator type M must provide the same interface as for amrex::GMRES: makeVecRHS, makeVecLHS, norm2, dotProduct, assign, increment, linComb, scale, setToZero, apply and precond.

Solve the linear system.

The initial guess is zero unless setInitialGuessNonzero(true) was called, in which case it is the value of a_sol on entry.
