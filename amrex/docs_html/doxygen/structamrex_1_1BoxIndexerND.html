Detailed Description

template<int dim, typename UIntT = detail::BoxIndexerUInt>
struct amrex::BoxIndexerND< dim, UIntT >

Utility that maps flattened point indices back to IntVectND coordinates.

The constructor captures a sequence of fast divmod helpers that implement fast division by the running products of box lengths, so repeated calls to intVect or the Dim3 functor avoid costly integer divisions while walking a BoxND.

Template Parameters
dimBox dimensionality.
UIntTIndex type, std::uint32_t or std::uint64_t. The 32-bit version is much cheaper on GPUs, but limits the box to fewer than 2^31 points. The default is 32-bit in GPU builds unless AMREX_ARRAY4_64BIT_INDEX is defined, and 64-bit in CPU builds. Use std::uint64_t for a large box that is not a fab box, e.g., a domain.
