Detailed Description

The state of setup reuse (HypreMLABecLap::setReuseSolverSetup, HypreMLNodeLap::setReuseSolverSetup).

A kept solver setup (hypre) or AlgMG hierarchy is for the matrix it was done with. A later matrix is scaled to that matrix's 2-norm (of the triplet values that depend on the coefficients, which fix the ratio) and the right-hand side with it, so that a uniform change of the coefficients, by a time step say, leaves the kept setup exact; otherwise its smoother weights and coarse corrections grow with the change until the preconditioner diverges. With a threshold (reuse_setup_max_change), a copy of the setup matrix's values is kept and the change of the scaled matrix since the setup is measured against it.
