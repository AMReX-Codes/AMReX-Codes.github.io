ParallelCopy that exchanges uniform blocks with a single MPI_Alltoall.

Every pair of processes exchanges a block of block_size bytes, padded if the actual message is smaller. This suits small messages, for which MPI libraries have logarithmic algorithms for MPI_Alltoall but not for MPI_Alltoallv. block_size must be the same on all processes and at least as large as the largest message. Other arguments are as in ParallelCopy_alltoallv.
