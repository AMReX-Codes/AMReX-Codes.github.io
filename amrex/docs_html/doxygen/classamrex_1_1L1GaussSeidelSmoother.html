Detailed Description

template<typename T>
class amrex::L1GaussSeidelSmoother< T >

l1 hybrid Gauss-Seidel smoother for CPUs.

Gauss-Seidel within each process, and within each of a fixed number of row blocks that the OpenMP threads share out; couplings to other blocks and to other processes use the previous iterate and their absolute values are added to the diagonal, which keeps the sweep convergent for any SPD matrix and any partition [Baker, Falgout, Kolev, Yang, SIAM J. Sci. Comput. 33 (2011), 2864-2887]. Forward and backward sweeps are available to keep a V-cycle symmetric. Not available in GPU builds.
