Detailed Description

BoomerAMG defaults.

GPU builds of HYPRE get HYPRE's recommended GPU options (PMIS coarsening, extended+i interpolation, l1-Jacobi relaxation in natural order, kept transposes); CPU builds keep the classical settings.
